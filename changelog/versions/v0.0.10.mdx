## Intro

Hello. Sorry it took so long for me to update the docs. I was having some issues with Mintlify. I got everything set, docs look much nicer (yay!),

## Main Changes

- **Web Ingestion:** Webpages are now a connector
- **Internet Search:** You can now search the internet and get an LLM response (with citations)
- **UI Updates:** Some improvements to the UI
- **Auth Change:** Switched to WorkOS. At this point, I have no active users, but if by some miracle you made an account prior to this update and are having issues with stuff,
reach out to me via the support tab
